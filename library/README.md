# library/ — the corpus

Scripture texts and language resources: translations/versions (public-domain
hosted here; copyrighted ones linked/API only), original languages (Hebrew,
Aramaic, Greek) with interlinear + lexicon data, and the wider canon (apocrypha /
deuterocanon / pseudepigrapha / "lost" books) labeled by tradition.

**Before adding anything here, read ../docs/03-texts-and-licensing.md.** Every
item must have a manifest entry: title, edition/year, language, tradition &
canon_status, source URL, and license.
