# Roadmap

Corpus first, then one app at a time. Each phase ships something usable and keeps
the licensing/manifest discipline of [03-texts-and-licensing.md](03-texts-and-licensing.md).

- **Phase 0 — Foundation (now):** vision, architecture, texts-&-licensing plan,
  dedication, contribution norms. *(This scaffold.)*
- **Phase 1 — The Library MVP:** normalized corpus schema + a manifest; ingest a
  few public-domain translations (start with the World English Bible + KJV);
  reader + side-by-side version compare; full-text search. Pick the app stack here.
- **Phase 2 — Original languages:** Hebrew + Greek texts, interlinear alignment,
  Strong's + lexicon, word study.
- **Phase 3 — The wider canon:** apocrypha / deuterocanon and the pseudepigrapha /
  "lost" books, each labeled by tradition (`canon_status`); a canon-comparison view.
- **Phase 4 — The Evidence layer:** manuscripts, verse-level textual variants with
  witnesses, and archaeology/history — all sourced.
- **Phase 5 — Sermon Studio:** topic/passage → gathered references, notes,
  outline, illustrations, export.
- **Phase 6 — Church Operations:** members, groups, events, communications, sermon
  archive; giving only via compliant integrations, later.
- **Ongoing — Community:** study tools, contributions, moderation, and translation
  (i18n) throughout.

Community and licensing discipline are not a phase — they run through all of it.
